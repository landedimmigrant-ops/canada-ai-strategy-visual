# Canada's National AI Strategy — Visual Explorer

An interactive, single-file visual breakdown of [Canada's National AI Strategy: AI for All](https://ised-isde.canada.ca/site/ised/en/canadas-national-artificial-intelligence-strategy-ai-all) (ISED, June 2026).

**Open `index.html` in any browser — no build, no dependencies, works offline.**

## What's inside

Six tabs, all driven by a shared sidebar with search and value/pillar filters:

- **Overview** — the strategy's architecture: three values (Trust, Opportunity, Sovereignty) carrying six pillars, plus the five priority sectors. Click a pillar for its themes and key actions.
- **For you** — pick an audience (SME owner, student, founder, researcher, worker, creator, Indigenous communities, public servant) and see only the programs that touch you.
- **Opportunities** — eight gap → response pairings showing the diagnosis behind each program, above a 31-card catalogue of every concrete program with dollar size and status.
- **Money flow** — a ribbon diagram tracing dollars from values → pillars → programs ($2.36B new named commitments, ~$6.2B leveraged), with line-by-line bars.
- **Targets** — headline tiles and baseline → target dumbbells (12% → 60% business adoption by 2034, 130 → 200 CIFAR chairs, 0 → 850 MW sovereign compute by 2030, and more).
- **Timeline** — every launch, dollar and target from Budget 2025 to 2050; click any entry for two lines of context.

## Sharing via GitHub Pages

The entry file is named `index.html`, so once this repo is on GitHub you can enable
**Settings → Pages → Deploy from branch** and the visual will be live at
`https://<username>.github.io/<repo>/`.
